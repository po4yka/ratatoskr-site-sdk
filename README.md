# Ratatoskr Site SDK

`@ratatoskr/site-sdk` and a starter template for a site that shows published notes of a Ratatoskr
vault. A site reads the current release of its publications through the anonymous Content Delivery
API (workspace change `add-site-publications`, ADR-0011).

The package and the template are in development. This file gets its full text with SITE-025 task
7.6.
